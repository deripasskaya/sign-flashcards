# 🚦 Дорожные знаки — флеш-карточки

Интерактивный сайт для заучивания дорожных знаков (ПДД РФ). Каждая карточка
показывает изображение знака (SVG), а при перевороте — его номер, название,
категорию и краткое пояснение.

## Возможности

- **Флеш-карточки с 3D-переворотом** — лицевая сторона со знаком, обратная — с названием и описанием.
- **121 знак** из 5 групп: предупреждающие, приоритета, запрещающие, предписывающие, особых предписаний.
- **Фильтр по категориям** с счётчиками.
- **Прогресс**: полоса и счётчик «X / N».
- **Отметка «Знаю» / «Не знаю»** — знаки делятся на выученные и ошибки.
- **Сводная таблица прогресса** (кнопка «📊 Сводка прогресса»): общий процент, счётчики
  «Выучено / Ошибки / Осталось», вкладки-фильтры (Все / Знаю / Не знаю / Не изучено) и
  таблица со всеми знаками. Клик по строке — переход к карточке этого знака.
- **Статус на карточке**: значок «Знаю» / «Не знаю» в углу.
- **Режим «Только невыученные»** и **перемешивание** набора.
- **Сохранение прогресса** в браузере (localStorage).
- **Горячие клавиши**: `←` `→` — навигация, `Пробел` — перевернуть, `↑` — «знаю»,
  `↓` — «не знаю», `Esc` — закрыть сводку.
- Адаптивная вёрстка (телефон/планшет/десктоп).

## Структура проекта

```
sign-flashcards/
├── index.html      # разметка страницы
├── styles.css      # оформление
├── app.js          # логика флеш-карточек
├── signs.js        # список знаков (генерируется скриптом)
└── icons/          # 126 SVG-файлов дорожных знаков
```

## Как запустить

Сайт статический — достаточно открыть `index.html` в браузере.

Вариант с локальным сервером (рекомендуется):

```bash
cd sign-flashcards
python3 -m http.server 8765
# затем откройте http://localhost:8765
```

## Обновление списка знаков

Файл `signs.js` сгенерирован из имён внутри SVG-файлов. Чтобы пересобрать его
после изменения набора, можно заново извлечь `<title>` каждого файла.
